# 📊 TL Report Generator

A web-based Excel automation tool that generates TL-wise operational reports from daily Payment Verification and Row Data files using dynamic Location-to-TL mapping.

Built with the assistance of AI to deliver a **fast, smooth, scalable, and efficient** user experience. The application automates Excel-based operational reporting, reduces manual effort, improves accuracy, and processes large datasets in seconds.

## ✨ Features

- 📂 Upload Excel files with an easy-to-use interface
- 📍 Persistent Location → TL Master Mapping
- ✅ TL-wise Payment Verification Summary (Yes / No / Total)
- 📦 Sent Back Report (Breach, Pending, No Breach, Sent Back)
- 📅 Dynamic Monthly Order Summary
- 🔍 Search, Filter & Sort Reports
- 📥 Export Reports to Excel & CSV
- ⚠️ Unknown Location Detection
- 📊 KPI Dashboard
- 🔄 Dashboard Reset
- 🚀 Optimized for large Excel files (50,000+ rows)

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- SheetJS (Excel Processing)

## 🚀 Why This Project?

This application was developed to eliminate repetitive Excel work by automatically processing daily operational files and generating accurate TL-wise reports with just a few clicks. It provides a clean, responsive interface and high-performance processing for business operations.
